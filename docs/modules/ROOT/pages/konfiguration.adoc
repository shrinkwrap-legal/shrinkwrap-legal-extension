= Konfiguration

Die Konfiguration wird zur Build-Zeit über `dotenv-webpack` eingebunden. Welche Datei gelesen wird,
bestimmt `NODE_ENV`: `.env` (kein `NODE_ENV`, Produktions-Build), `.env.development`, `.env.remote`.

[cols="1,2,2,2"]
|===
| Variable | `.env` (Produktion) | `.env.development` | `.env.remote`

| `API_BASE_URL` | `https://api.shrinkwrap.legal` | `http://localhost:8080` | `https://api.shrinkwrap.legal`
| `OPEN_ON_INSTALL` | `https://api.shrinkwrap.legal/api/extension-install` | `false` | `false`
|===

`API_BASE_URL`:: Basis-URL der xref:api::index.adoc[Shrinkwrap.Legal API]. Die API muss vom Browser aus erreichbar sein und CORS erlauben.
`OPEN_ON_INSTALL`:: URL, die nach der Erstinstallation in einem neuen Tab geöffnet wird; `false` deaktiviert das.

Zusätzlich setzt Webpack `process.env.TARGET_BROWSER` (`chrome` oder `firefox`).

== Benutzereinstellungen

Einstellungen werden in `storage.local` gespeichert:

[cols="1,3"]
|===
| Schlüssel | Bedeutung

| `headline` | Welche Information in den RIS-Trefferlisten als Überschrift angezeigt wird (Side Panel)
| `searchStandard` | Standard-Dokumenttyp der Suche, z. B. `TE` (Entscheidungstext) statt Rechtssatz; Standard `TE`
| `disableInfoModal` | `Y`, wenn der Info-Dialog nicht mehr angezeigt werden soll
|===
